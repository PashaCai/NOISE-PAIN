# 声的形状 / SOUND, FELT.

面向非噪敏人群的声音感知作品。使用十段原始录音，将频谱与能量变化转译为钴蓝等高线和颗粒形态。此转译是艺术表达，不是个体痛苦程度的测量。

## 打开

直接用 Chrome / Edge 打开 `index.html` 即可使用，所有资源均在本文件夹中，没有 CDN 或外部字体依赖。

也可以在安装 Node.js 18+ 的电脑上运行：

```sh
node server.cjs
```

浏览器打开 `http://127.0.0.1:4173`。部署时把本目录完整上传到任意静态网站托管即可；本地服务器仅绑定本机，不会公开上传音频。

## 交互

- 打开页面尝试有声自动播放；浏览器拦截时，点击「进入声音体验」解锁。不能绕过浏览器的自动播放策略。
- 切换声音从头自动播放，保留用户选择的音量与静音状态。默认音量 35%，默认单曲循环。
- 拖动扭转并局部挤压形态；滚轮或 +/- 缩放；双击、复位按钮或画布上按 0 复位。
- 空格播放/暂停（焦点不在其他按钮或输入上时）；Esc 暂停。
- 波形可点击或拖动定位，进度条支持键盘；列表支持上下箭头。
- 静音保留声音时间轴和可视化；暂停同时冻结声音时间。

## 技术

- 原生 HTML / CSS / JavaScript，无框架与构建步骤。
- WebGL 2 自定义 GLSL 标量场：FBM 噪声、音频频谱驱动的角向形变、导数抗锯齿等值线、像素墨点。无 WebGL 时使用 Canvas 2D 简化轮廓。
- 延续前一个 openFrameworks 项目的暖白纸面、蓝墨与中心颗粒效果；没有将 C++ 程序嵌入网页。
- 每段原始 44.1 kHz、16-bit 立体声录音均完整保留，SHA-256 在 `audio-analysis.json`。
- 8192 点 Hann 窗 FFT，20 帧/秒，左右声道分别求功率后平均，避免相位相消；24 个对数频带和 3 个宽频段。分析覆盖整段原音频，不以编号随机生成形态。
- `profiles.js` 存储逐帧特征，播放时按 `audio.currentTime` 插值，同步声音、进度条与图像。静音仍准确显示原始频谱。未播放时展示该音频全段能量加权特征，避免以录音开头静音生成空图。
- 低频（20–250 Hz）映射大尺度起伏，中频（250–2000 Hz）映射折叠，高频（2000–20000 Hz）映射细节密度和尖锐纹理；RMS 包络映射形变幅度，包络正向变化映射冲击。
- 每条声音的 RMS 以自身 95 百分位归一化以便观察形变，所以不同录音的视觉幅度不能解释为绝对响度对比。频带占比为数字录音相对能量，不是声压级或医学指标。
- HTTP 模式下启用 Web Audio 音频图；时间对齐的离线 FFT 为视觉主驱动。file:// 模式直接使用原生音频播放。
- 尊重系统减少动态效果设置，降低形变与瞬态幅度；不会改变原录音。

`1.wav` 至 `10.wav` 未附场景名称，故界面保留中性编号及分析所得频段标签，没有猜测声源。可在 `profiles.js` 的 `title` 字段更名。
